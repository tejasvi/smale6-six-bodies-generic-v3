# Cofactor certificates for the kernel checks (Lemma 7.9 over F_32003 at μ₀ = (3,5,7,11); Lemma 6.19(a) escape rays)

Each certificate shows that 1 lies in the ideal generated by a system of polynomials over F_p: it lists cofactors
`c_k` with `Σ_k c_k f_k = 1` in `F_p[x]`. All were computed by Singular 4.4.1 (`liftstd`, the first column of the
transformation matrix of the standard basis `{1}`) and checked independently with python-flint 0.9.0 (`nmod_mpoly`)
against the systems as the Lean development builds them (`verify_cof.py`, `verify_esc.py`).

## Lemma 7.9 (14 charts, p = 32003, μ₀ = (3,5,7,11)): `c4_3_5_7_11_<chart>.cert`

* System: `Lean6.Special.Comp.C4.chartEqs [3, 5, 7, 11] ch` (11 polynomials, in that order), the equations of Z(μ₀) with
  the two chart variables set to 1, as dumped by `gen/c4/dump_eqs.lean` (`lean_eqs.txt`).
* Variables: `s, t, p12, p13, p14, p23, p24, p34, c` (indices 0–8, the order of `C4.Sys`); the two chart variables have
  exponent 0 in every term.
* Format: one line per term, `k c e0 e1 … e8`: cofactor of equation `k` (from 0), coefficient `c ∈ [0, 32003)`,
  exponents. Terms of each cofactor in decreasing degree-reverse-lexicographic order (as python's tuple sort; the
  order is irrelevant to the identity).

## Lemma 6.19(a), the escape rays (p = 65521): `esc_kc_0.cert`, `esc_n4_0.cert`

* System: `hypsKC`, `hypsN4` (`Lean6.Special.Comp.D88.Trop`, read from `DataKC.hypStr`, `DataN4.hypStr`; the JSON
  files `kc_hyps.json`, `n4_hyps.json` give the same polynomials, compared token by token with the strings): one
  system each, 101 and 30 polynomials in the 17 coordinates.
* Format: `k c e0 … e16`, coefficient in `[0, 65521)`.

## Files

The certificates themselves (524 MB as text, 71 MB with `xz -6`) are distributed separately; `SHA256SUMS` lists the
digests of the uncompressed files. `summary.txt`: the number of cofactor terms, the result of the independent check,
and the time and memory of each `liftstd` run (one core of a 384-core machine).

Regenerate: `python3 -I gen/kern/mk_lift.py OUT HYPSDIR` (HYPSDIR: the output directory of `gen/d88trop/run.sh`
with `n4_hyps.json`, `kc_hyps.json`), then in `OUT` run `Singular -q <name>.sing` (with `cof/` present), then
`verify_cof.py LEAN_EQS "[3, 5, 7, 11]" <chart> 32003 cof/<name>.txt <name>.cert` (LEAN_EQS: the output of
`lake env lean gen/c4/dump_eqs.lean`) and `verify_esc.py HYPSDIR/<kind>_hyps.json 0 65521 cof/<name>.txt <name>.cert`.
The system `esc_n4_0` did not finish within 6 h (56 GB), so it has no certificate.
